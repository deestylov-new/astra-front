# Астра

Демо web-приложения личного помощника для путешественника, работающего удалённо.

## Возможности

- управление бронированиями и поездками;
- планирование бюджета и регулярных операций;
- события, цели и чек-листы;
- финансовые накопления;
- agile-доска задач;
- настройки и интеграции.

## Запуск

```bash
pnpm install
pnpm dev
```

Production-сборка:

```bash
pnpm build
```
